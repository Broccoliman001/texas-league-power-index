About This Project

The Texas League Power Index is an independent sports analytics project covering the league's 10 Double-A baseball clubs. It processes current standings and game results into a comparative team-strength rating and publishes the results through an interactive web dashboard.

Unlike traditional standings, the index considers not only whether a team wins, but also how strongly it performs and the quality of the opponents it has faced. The Power Index can be viewed across the full season, either official half, or each team's rolling recent window. The playoff section remains separate from the descriptive Power rankings: it follows the official split-season standings and uses current team-strength signals, the remaining schedule, home field, and official tiebreak procedures to estimate each eligible team's chance of earning the open berth.

How the Power Score Is Calculated

The Texas League Power Index is a weighted analytical rating designed to measure team strength beyond simple win-loss record. The selected view determines which games are included, and then each component is normalized across the league within that same view before the weighted score is calculated.

  • 50% Run differential per game in the selected view
  • 25% Actual winning percentage in the selected view
  • 25% Average opponent winning percentage in the selected view

How to read the score: Power scores are centered around 50. Scores above 50 indicate stronger-than-average performance within the selected view, while scores below 50 indicate weaker-than-average performance. Because each view is normalized independently, Power values should be compared within a view rather than subtracted across different views. Power is not a projected winning percentage.

Run Differential Per Game

Run differential measures how many more or fewer runs a team has scored than it has allowed. Dividing by games played allows teams with slightly different game totals to be compared on the same scale.

Winning Percentage

Actual winning percentage ensures that game outcomes remain a direct part of the rating. Teams receive credit for consistently converting their underlying performance into wins.

Opponent Winning Percentage

OWP stands for Average Opponent Winning Percentage. It measures schedule strength by averaging each opponent's winning percentage from the same selected view after excluding games that opponent played against the team being evaluated. Opponents are still weighted by the number of games played against them. This prevents a team's own wins or losses from directly changing the schedule-strength credit it receives.

Understanding the Views

Overall uses every completed regular-season game. First Half and Second Half use the official split-season game sets. Recent uses each team's most recent 24 completed games (or all available games before 24 have been played), so teams' Recent windows can begin on different dates. The same Power formula is applied separately inside each view.

Rating Behavior

Power Scores are designed to behave like long-term team-strength ratings rather than a daily recreation of the standings.

  • Ratings use the body of work defined by the selected view.
  • Overall and Second Half expand as games are completed; First Half freezes when that official half is complete; Recent rolls forward one game at a time once a team has 24 completed games.
  • Overall, First Half, and Second Half are smoothed using previously published ratings to reduce excessive movement from a single new result. Recent is not additionally smoothed because its rolling 24-game window already provides temporal smoothing.
  • Final scores are compressed toward the league average so the scale remains readable within each view.
  • Trend arrows compare current rank with the weekly baseline snapshot from Monday, or the first available snapshot of the week.
  • The accompanying positive or negative value shows the change in Power score against that same weekly baseline.

Project Architecture

Current game, standings, and schedule data are processed into a structured JSON dataset containing four Power views, team records, run totals, opponent strength, rating components, historical movement, recent game results, half-season standings, playoff qualification state, remaining matchups, and model-estimated playoff berth probabilities.

The browser loads the latest dataset and dynamically renders the selected Power view, trend indicators, score changes, completed games, and active playoff races. The rankings controls switch among Overall, First Half, Second Half, and Recent without reloading the page. The playoff section independently reads the active-half state and forecast output, including comparative forecast strength and Monte Carlo berth odds generated from the remaining schedule. The responsive layout is designed to remain usable on desktop and mobile screens.
