About This Project

The Texas League Power Index is an independent sports analytics project covering the league's 10 Double-A baseball clubs. It processes current standings and game results into a comparative team-strength rating and publishes the results through an interactive web dashboard.

Unlike traditional standings, the index considers not only whether a team wins, but also how strongly it performs and the quality of the opponents it has faced.

How the Power Score Is Calculated

The Texas League Power Index is a weighted analytical rating designed to measure full-season team strength beyond simple win-loss record. Each component is normalized across the league before the weighted score is calculated.

  • 50% Full-season run differential per game
  • 25% Full-season actual winning percentage
  • 25% Full-season average opponent winning percentage

How to read the score: Power scores are centered around 50. Scores above 50 indicate stronger-than-average full-season performance, while scores below 50 indicate weaker-than-average performance. Power is a comparative rating within the current Texas League season and is not a projected winning percentage.

Run Differential Per Game

Run differential measures how many more or fewer runs a team has scored than it has allowed. Dividing by games played allows teams with slightly different game totals to be compared on the same scale.

Winning Percentage

Actual winning percentage ensures that game outcomes remain a direct part of the rating. Teams receive credit for consistently converting their underlying performance into wins.

Opponent Winning Percentage

OWP stands for Average Opponent Winning Percentage. It measures schedule strength by averaging the current winning percentage of every opponent a team has played, weighted by the number of games played against each opponent.

Expected Record

X-W/L estimates the record normally associated with a team's runs scored and runs allowed. It provides additional context for teams whose actual record is substantially better or worse than their scoring performance would suggest. Expected record is displayed for interpretation but is not added as a separate Power Score component.

Rating Behavior

Power Scores are designed to behave like long-term team-strength ratings rather than a daily recreation of the standings.

  • Ratings use each team's full-season body of work.
  • Scores are smoothed using previously published ratings to reduce excessive movement from a single game.
  • Final scores are compressed toward the league average so the scale remains readable and comparable.
  • Trend arrows compare current rank with the weekly baseline snapshot from Monday, or the first available snapshot of the week.
  • The accompanying positive or negative value shows the change in Power score against that same weekly baseline.

Project Architecture

Current game and standings data are processed into a structured JSON dataset containing team records, run totals, expected records, opponent strength, rating components, historical movement, and recent game results.

The browser loads the latest dataset and dynamically renders the rankings table, trend indicators, score changes, and completed games. The responsive layout is designed to remain usable on desktop and mobile screens.
